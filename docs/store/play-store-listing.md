## Play Console — step-by-step first release

1. **Register** at https://play.google.com/console ($25 one-time).
   ⚠ **Account type matters**: a **personal** account must run a **closed test with at least 12 testers for 14 consecutive days** before it can apply for production access. An **organization** account (needs a D-U-N-S number) skips this. Identity verification can take a few days either way.
2. **Create app**: name `UPK – Ultimate Poker Kit`, default language English (US), **Game**, **Free**, accept declarations.
3. **Play App Signing** (Setup → App signing): accept the default Google-generated app signing key. The EAS keystore automatically becomes the *upload* key.
4. ⚠ **Fix Google Sign-In for Play builds**: Play re-signs the app, so its SHA-1 differs from the EAS keystore's. In Setup → App signing, copy the **App signing key certificate SHA-1** and in https://console.cloud.google.com → APIs & Services → Credentials (same project as the existing clients), create a **second Android OAuth client**: package `fr.upk.app` + that SHA-1. Without it, Google Sign-In works on sideloaded APKs but **fails on the Play-distributed app**. (Nothing to copy back — the client just needs to exist.)
5. **Store listing** (Grow → Store presence → Main store listing): paste the en texts above, upload `icon-512.png`, `feature-graphic.png` and the `store/screenshots/android/en/` set. Then add a **French (France)** localization with the fr texts + `android/fr/` screenshots.
6. **Store settings**: category Card, contact email, website `https://upk-api.fly.dev/support`.
7. **App content** (Policy → App content): work through every section using the answers above (privacy policy, ads, app access, content rating, target audience, data safety, financial features, government/news).
8. **Build the AAB**:
   ```sh
   cd apps/mobile && eas build -p android --profile production
   ```
   Download the `.aab` from the EAS build page.
9. **Release**: Testing → Closed testing (mandatory first for personal accounts) or Production → Create release → upload the AAB → the first upload enrolls the app in Play App Signing → do step 4 now if not done → review release notes → roll out. Check the pre-launch report once bots have run the app.
10. First review typically takes a few days (sometimes longer with a simulated-gambling rating). Subsequent updates are faster.

### Later: automate uploads with `eas submit`

The **first** AAB must be uploaded through the Console UI. For updates:
1. Google Cloud Console → create a **service account**, grant it access in Play Console (Users and permissions → invite the service-account email, releases permission), download its **JSON key** (keep it out of git — e.g. `~/keys/upk-play-service-account.json`).
2. Add to `apps/mobile/eas.json`:
   ```jsonc
   "submit": { "production": { "android": { "serviceAccountKeyPath": "/Users/remy/keys/upk-play-service-account.json", "track": "production" } } }
   ```
3. Then: `eas build -p android --profile production` + `eas submit -p android --latest`.
